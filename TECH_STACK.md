# Technology Stack

This document outlines the technology stack for the URL Shortener service.

## Core Technologies

*   **Java 21**
*   **Spring Boot 3**
*   **Maven**

## Testing Strategy

Our testing strategy will follow a multi-layered approach to ensure the quality and reliability of the service.

### Future Implementations

*   **Acceptance Test-Driven Development (ATDD):** We will use ATDD to ensure that the application meets the business requirements. This will involve writing acceptance tests in collaboration with stakeholders before development begins.
*   **Unit Testing:** We will write unit tests for all new code to ensure that individual components are working correctly.
*   **WireMock:** We will use WireMock for stubbing and mocking external services during integration and end-to-end testing.
